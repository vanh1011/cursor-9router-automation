# Cursor 9Router Automation

macOS scripts that turn 9Router on or off, create a public tunnel, and update the new URL in Cursor automatically.

## Why

If you do not have a server to host 9Router permanently, you need to run 9Router on your local machine. However, Cursor does not allow a local HTTP URL to be used directly as the OpenAI Base URL, so a public tunnel is required.

Each time 9Router starts, the tunnel may generate a new URL. Copying that URL and manually updating Cursor every day is slow and error-prone.

## Solves This

These scripts automate the whole flow:

- Turn 9Router on or off with one command.
- Create a public tunnel and read the latest URL.
- Append `/v1` to the endpoint.
- Automatically update `openAIBaseUrl` in Cursor.
- Restart Cursor so the new configuration is applied.

## How It Works

### `9router-on`

1. Checks required dependencies and Cursor's configuration database.
2. Starts 9Router at `127.0.0.1:20128`.
3. Enables the Quick Tunnel managed by 9Router and reads the public URL.
4. Closes Cursor safely and backs up the configuration database.
5. Updates `openAIBaseUrl` with the tunnel URL plus the `/v1` suffix.
6. Opens Cursor again after the update succeeds.

If the database update fails, the script restores the backup together with the related SQLite WAL/SHM files.

### `9router-off`

1. Finds 9Router, the listener on port `20128`, and the related tunnel process.
2. Sends `SIGTERM` so the processes can stop safely.
3. Uses `SIGKILL` only if a process does not respond after the timeout.

## Requirements

- macOS.
- Cursor installed and launched at least once.
- 9Router CLI available in `PATH`.
- System utilities: `zsh`, `python3`, `pgrep`, `lsof`, `ps`, `sort`, `tr`, `osascript`, and `open`.
- 9Router local tunnel data available under `~/.9router`.

Check 9Router:

```zsh
command -v 9router
```

## New Device Setup

Use this section when setting up a Mac that does not already have 9Router, Cursor, or the tunnel data prepared.

### 1. Install Cursor

Install Cursor, open it once, then close it. This creates the local settings database that the script updates later.

### 2. Install 9Router

Install 9Router using the method recommended by the 9Router project, then confirm the CLI is available:

```zsh
command -v 9router
```

If the command is not found, make sure the 9Router binary is installed and available in your shell `PATH`.

### 3. Start 9Router Once Manually

Run 9Router once before using the automation script:

```zsh
9router --tray --skip-update --no-browser --port 20128 --host 127.0.0.1
```

Then open the local dashboard:

```text
http://127.0.0.1:20128
```

### 4. Connect a Provider

In the 9Router dashboard, connect at least one provider and copy the API key generated by 9Router. For Cursor, use 9Router as an OpenAI-compatible endpoint:

```text
Endpoint: http://127.0.0.1:20128/v1
API Key:  [copy from 9Router dashboard]
Model:    a model ID shown by 9Router, for example kr/claude-sonnet-4.5
```

Even when the model behind 9Router is Claude, Cursor should still be configured through the OpenAI-compatible settings because 9Router translates between OpenAI and Claude formats.

### 5. Enable the 9Router Tunnel Once

Enable the Quick Tunnel from the 9Router dashboard at least once. This prepares the local tunnel state under `~/.9router`, which the automation script reads later.

> You do not need to install or configure Cloudflare Tunnel separately if you are using the tunnel managed by 9Router. The script expects 9Router to manage the tunnel and write its state to:
>
> ```text
> ~/.9router/tunnel/state.json
> ```

### 6. Run This Automation

After the new device has Cursor, 9Router, a connected provider, and prepared tunnel state, clone this repository into any local folder you like, then run the script from the cloned repository directory:

```zsh
cd ~/Documents
git clone <this-repository-url>
cd cursor-9router-automation
chmod +x 9router-on 9router-off
./9router-on
```

## Quick Start

Clone this repository into any local folder you like, then enter the project directory:

```zsh
cd ~/Documents
git clone <this-repository-url>
cd cursor-9router-automation
```

Grant execute permission the first time:

```zsh
chmod +x 9router-on 9router-off
```

Start 9Router, enable the tunnel, and configure Cursor:

```zsh
./9router-on
```

Stop 9Router and the tunnel:

```zsh
./9router-off
```

> `9router-on` may close and reopen Cursor. Save any work in progress before running it.

## Run From Any Terminal

If you want to open Terminal and type `9router-on` from anywhere, link the scripts into your user bin folder.

From inside the cloned repository:

```zsh
chmod +x 9router-on 9router-off
mkdir -p "$HOME/bin"
ln -sf "$PWD/9router-on" "$HOME/bin/9router-on"
ln -sf "$PWD/9router-off" "$HOME/bin/9router-off"
```

Then you can run:

```zsh
9router-on
9router-off
```

Check that your shell can find the commands:

```zsh
command -v 9router-on
command -v 9router-off
```

If `command -v` prints nothing, add `~/bin` to your shell `PATH`:

```zsh
echo 'export PATH="$HOME/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```

To remove the user commands later:

```zsh
rm -f "$HOME/bin/9router-on" "$HOME/bin/9router-off"
```

## Related Files and Data

- 9Router log: `~/.9router.log`
- Tunnel state: `~/.9router/tunnel/state.json`
- Cursor database:
`~/Library/Application Support/Cursor/User/globalStorage/state.vscdb`
- Latest backup: `~/.cursor-state.vscdb.backup`

## Limitations

- These scripts are currently macOS-only.
- Port `20128` is hard-coded in both scripts.
- Cursor's internal settings storage may change after an update. Recheck the script if Cursor no longer picks up the Base URL.
